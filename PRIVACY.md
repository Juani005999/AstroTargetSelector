# Politique de confidentialité – AstroTargetSelector (Android)

*Dernière mise à jour : 3 octobre 2026*

***AstroTargetSelector*** est une application gratuite, sans publicité, développée par Juanito del Pepito (AstroTools).

## Données collectées
**AstroTargetSelector ne collecte, ne transmet et ne partage aucune donnée personnelle.**

L'application fonctionne entièrement hors ligne : elle ne demande pas l'accès à Internet, ne contient aucun outil de mesure d'audience, aucune publicité et ne nécessite aucun compte.

## Localisation
L'application peut accéder à la position du téléphone, uniquement lorsque vous touchez le bouton **Utiliser la position du téléphone** dans l'onglet ***Paramètres***, et seulement si vous l'autorisez.

Cette position sert uniquement à renseigner le lieu d'observation, utilisé pour calculer la position des objets célestes. Elle est enregistrée uniquement sur votre téléphone, dans les paramètres de l'application, et n'est jamais transmise.

Vous pouvez à tout moment saisir le lieu d'observation manuellement, ou retirer l'autorisation de localisation dans les paramètres d'Android.

## Données enregistrées sur le téléphone
Les paramètres de l'application (lieu d'observation, capteur, options d'affichage...) sont enregistrés uniquement sur votre téléphone. Ils sont supprimés lorsque vous désinstallez l'application.

## Contact
Pour toute question : [page GitHub d'AstroTargetSelector](https://github.com/Juani005999/AstroTargetSelector).

# Privacy policy – AstroTargetSelector (Android)

*Last updated: October 3, 2026*

***AstroTargetSelector*** is a free, ad-free application developed by Juanito del Pepito (AstroTools).

## Data collection
**AstroTargetSelector does not collect, transmit or share any personal data.**

The application works entirely offline: it does not request Internet access, contains no analytics, no advertising, and requires no account.

## Location
The application may access the phone's location, only when you tap the **Use the phone's position** button in the ***Settings*** tab, and only if you allow it.

This location is only used to fill in the observation site, which is used to compute the position of celestial objects. It is stored only on your phone, in the application settings, and is never transmitted.

You can enter the observation site manually at any time, or revoke the location permission in Android settings.

## Data stored on the phone
The application settings (observation site, sensor, display options...) are stored only on your phone. They are deleted when you uninstall the application.

## Contact
For any question: [AstroTargetSelector GitHub page](https://github.com/Juani005999/AstroTargetSelector).
